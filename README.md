# 赛博日常（AstrBot 插件）

给 AstrBot 加一个**有内置浏览器、会自己刷帖、会评论、会画画、还有心情**的日常模块。

- 🔐 **扫码登录**：B站、小黑盒、贴吧；登录态持久化在本机，不需要密码
- 🧭 **内置浏览器**：Playwright + 本机 Edge/Chrome，用于小黑盒 / 贴吧的扫码、刷帖和评论
- 🕒 **自动峰谷 + 节假日**：不再手填峰谷时间；工作日按 09:00–12:00、14:00–18:00 判峰时，周末和法定节假日全天开放；支持调休上班日
- 🪄 **工具自调用**：bot 仍可自己调用 `cyber_life_*` 工具和按计划刷帖；**聊天自动触发和自主提示词默认关闭**，普通聊天不会被关键词或分类器接管
- 📣 **后台留档，聊天可查**：每轮刷到的标题、识别摘要、评论/回复正文和链接都会写入 AstrBot 日志和活动记录；默认允许 bot 在聊天里查看和说明，但不会主动推送到会话
- ⏳ **自主使用时间**：bot 可以直接修改每日上限、本次时长和访问模式，不是只汇报“我刷完了”
- 💳 **DeepSeek 余额**：控制台和聊天都能查当前账户余额；只使用 AstrBot 当前 DeepSeek 提供商的 Key，不把 Key 返回前端
- 💬 **显式命令**：想稳定执行时用 `/life play` `/life run`；自然语言直连是可选开关，默认关，避免误触
- ✍️ **自动评论 + 回复**：频率、每日上限、评论概率都可调
- 📺 **视频理解**：不是逐帧识别，而是按视频时长抽 **10–20 帧**，合成一张带时间戳的关键帧总览图，再交给视觉模型；短视频不足 10 帧也照样合成识别
- 🎧 **声音转字幕**：优先读取B站 AI 字幕；没有字幕时提取音轨，用本地 faster-whisper 听写。转写文本会参与视频理解、自动评论和后台记录，所以没声音/静音看视频也能知道说了什么
- 🎨 **ComfyUI 画画**：没事时根据当前心情生成提示词并出图，可发回聊天
- 💗 **动态心情卡**：聊天内容、刷到的视频、画画结果都会影响高兴 / 精力 / 好奇 / 压力，设置页实时显示心情卡和历史曲线
- 🖥 **可视化设置页**：账号管理、扫码、二维码状态、自动峰谷访问模式、频率、通知、依赖状态、最近动态

## 安装

GitHub 仓库：<https://github.com/zqjiujih201015-del/astrbot_plugin_cyber_life>

在 AstrBot 插件页选择「从 URL 安装」，填入上面的仓库地址即可；也可以下载 Release 里的 zip 上传。

发布版通过 `requirements.txt` 安装 Playwright、qrcode、imageio-ffmpeg，AstrBot 安装插件时会自动处理。离线包或本机完整包可以把这些依赖放进 `vendor/`，这样不联网也能跑；Git 仓库不提交 `vendor/`，以保持插件市场要求的体积。

本地语音听写是可选能力：需要 `requirements.txt` 里的 `faster-whisper`（会自带 PyAV）。如果只复制文件夹而没有让 AstrBot 安装依赖，先在 AstrBot 的 Python 环境执行：

```powershell
pip install "faster-whisper>=1.2,<1.3" "zhconv>=1.4"
```

不装也能用：B站视频有 AI 字幕时照样能转成文字。只有「B站没有字幕」的视频才需要本地模型。首次本地听写会自动下载 Whisper 模型（默认 `small` 约 460MB）到 `plugin_data/astrbot_plugin_cyber_life/models/asr/`，之后复用。

1. 关闭或暂停 AstrBot 插件热重载（可选）。
2. 把整个 `astrbot_plugin_cyber_life` 文件夹复制到 AstrBot 的
   `core/data/plugins/` 下。
   也可以运行：

   ```powershell
   powershell -ExecutionPolicy Bypass -File .\install.ps1
   ```

   自动找不到时手动指定：

   ```powershell
   powershell -ExecutionPolicy Bypass -File .\install.ps1 -PluginsDir "C:\...\core\data\plugins"
   ```

3. 打开 AstrBot WebUI → 插件 → **重载插件**。
4. 进入插件详情 → 打开 **赛博日常控制台** 视图。

> 浏览器使用本机已安装的 Edge（默认 `msedge`）或 Chrome。若启动失败，在设置页把「浏览器通道」改成 `chrome`，或填写 `browser_executable` 的完整路径。
>
> 首次使用小黑盒 / 贴吧扫码时，如果无头浏览器截不到二维码，把「浏览器无头模式」关掉再试。

## 第一次使用

1. 在控制台「账号」页点 B站 / 小黑盒 / 贴吧的「扫码登录」。
2. 二维码会同时发到最后一次聊天的会话；用手机 App 扫码。
3. B站扫码后会自动确认；小黑盒 / 贴吧如果页面没自动识别，点弹窗里的「我扫完了，手动确认」。
4. 登录成功后账号状态变成「在线」，之后刷帖、评论都会复用这份登录态。
5. 到「设置」里选择访问模式（仅谷时 / 全天开放），再确认评论/回复频率，保存即可。

## 命令与聊天触发

插件注册了 15 个 AstrBot LLM 工具（`cyber_life_*`）。主模型仍可能根据工具描述自己调用；但**插件默认不会抢占普通聊天**：

- 「自主提示词」默认关：不向主模型注入“去刷帖/去登录”的操作提示；
- 「聊天自动触发」默认关：模糊说法不会被意图分类器接管；
- 但明确说“去贴吧刷十分钟 / 你刷会小黑盒”仍然会直接执行，不会只口头答应；
- 缺账号自动发二维码仍然保留，但只在 bot 真正要执行活动时触发。

想稳定执行时用命令：

```text
/life play bilibili 15
/life run 10
/life status
/life activity 10
```

刷完的动态默认写入活动记录和 AstrBot 日志，**不会主动发到聊天**；但 bot 可以在你问起时读取并说明刷了什么、评论了什么。若把设置页「活动记录仅内部可见」打开，则会切断聊天对记录的访问，只保留内部留档。

明确任务会立即执行，不等待下一次刷帖间隔；贴吧 / 小黑盒可以一次指定一个或两个平台。活动记录里会保存：刷到的标题和摘要、自己发的评论、评论区前几条、别人回复的原话。小黑盒使用社区页 `https://www.xiaoheihe.cn/app/bbs/home`，不再打开没有帖子列表的官网首页。

明确说“去B站看会儿 / 贴吧刷十分钟”不需要这两个开关。如果想让更模糊的说法也被直接执行，再到设置页打开「聊天自动触发」和「自主提示词」：

- “我有点无聊，找点事做 / 你随便逛逛吧”
- “去B站看会儿视频 / 小黑盒有什么新东西 / 贴吧逛逛”
- “帮我登录一下B站 / 换个号”
- “今天多玩半小时 / 以后每天只能玩一小时”
- “DeepSeek 还有多少钱 / 余额多少”

关闭后，普通聊天、情绪倾诉、提到 B站/贴吧都不会再自动弹出“好，我去 B站逛 15 分钟”。

### 聊天不响应时

1. 确认 AstrBot 里插件是启用状态，并且已经点过“重载插件”。
2. 私聊/群里发 `/life status`；如果回“没有权限”，把插件配置里的 `allow_qq` 填成你的 QQ 号。
3. 设置页确认「缺账号自动发二维码」是开启的。
4. 想让自然语言直达，再手动打开「聊天自动触发」；否则请用 `/life` 命令。

## 自动峰谷

不再需要手填峰时/谷时时间：

- 工作日 **09:00–12:00、14:00–18:00** 自动判为峰时
- **周末和法定节假日全天开放**，不设峰时限制
- 其余时间为谷时
- 自动识别**调休上班日**（周末补班按工作日处理）

节假日数据来自 `holiday-cn` 官方日历，首次启动会联网同步并缓存；插件内置了 2026 年数据，断网时也能识别 2026 年节假日。设置页可以额外添加：

- `extra_holiday_dates`：公司/学校额外休息日
- `extra_workday_dates`：额外调休上班日

格式都是 `YYYY-MM-DD`。

设置页只有两个选项：

| 选项 | 行为 |
|---|---|
| **仅谷时可用** | 峰时 bot 不响应游玩、画画、看视频；谷时才开放 |
| **全天开放** | 任何时间都能调用；子选项「峰时使用频率」控制峰时自动活动的频率（40% = 间隔约为谷时的 2.5 倍） |

登录、查看状态、暂停/恢复这类管理操作不受峰时限制，方便你在峰时也能扫码登录。

## 设置页

- **概览**：心情卡（高兴值、四维条、历史曲线）、今日刷帖/评论/回复/画画进度、运行状态、依赖检查、下次动作时间
- **账号**：平台登录状态、扫码弹窗、已保存账号、切换当前账号、删除登录态
- **设置**：总开关、自主提示词、聊天自动触发（两项默认关）、缺账号自动发二维码、Bot 自行调整使用时间、DeepSeek 余额卡、自动峰谷的两个访问模式、峰时使用频率、法定节假日识别、额外休息/上班日、评论与回复间隔、每日上限、评论概率、平台、截图张数、语音转字幕（开关、Whisper 模型、语言、最长秒数、下载镜像）、ComfyUI、浏览器、通知（「活动记录仅内部可见」默认关，聊天可查；「主动发动态到会话」默认关，不主动推送）
- **动态**：刷到的视频、评论内容、回复、画画记录和错误

设置保存在插件数据目录的 `settings.json`，**改完立即生效，不需要重载插件**。

## HTTP 接口

以下接口挂在 AstrBot 插件 Web API 下，需要仪表盘登录态（和插件页面相同的鉴权）：

| 方法 | 路径 | 说明 |
|---|---|---|
| GET / POST | `/api/plug/astrbot_plugin_cyber_life/deepseek/balance` | 查 DeepSeek 余额；GET 有 60 秒缓存，POST 强制刷新 |
| GET / POST | `/api/plug/astrbot_plugin_cyber_life/usage` | 查/改使用时间；POST 可传 `daily_watch_minutes`、`session_minutes`、`access_mode`、`peak_frequency_percent` |

余额接口返回：

```json
{
  "ok": true,
  "is_available": true,
  "balances": [
    {
      "currency": "CNY",
      "total_balance": "62.56",
      "granted_balance": "0.00",
      "topped_up_balance": "62.56"
    }
  ],
  "fetched_at": "2026-10-26T01:00:49+08:00",
  "cached": false
}
```

接口只返回余额，不会返回 API Key。Key 从 AstrBot 当前 DeepSeek 提供商读取；如果使用代理，可在设置页填写「余额接口地址」。实际请求的是 `GET {base}/user/balance`。

## 视频抽帧规则

`core/montage.py`：

- 目标帧数 = 视频时长 / 6 秒，再夹在 `video_min_frames`（默认 10）和 `video_max_frames`（默认 20）之间；
- 不会超过「每秒 2 帧」的物理上限，所以 3 秒短视频会少于 10 帧；
- 无论最终几帧，**都会合成一张图**再送视觉模型，不足 10 帧不报错；
- 每格带时间戳，整张图带标题、平台、作者、简介；
- 超过 `video_max_seconds` 的视频直接跳过下载，避免磁盘被大文件占满。

视觉模型不可用时自动降级为「标题 + 简介」推断，不会卡住活动循环。

## 语音转字幕

视频理解会同时看画面和声音，`core/transcribe.py`：

1. **B站 AI 字幕优先**：登录后读取播放器的 `ai-zh` / 中文轨道，速度很快，专有名词通常比本地听写准；
2. **本地 Whisper 兜底**：视频没有字幕时，用 ffmpeg 抽出 16kHz 单声道音轨，交给 faster-whisper（默认 `small`、int8、CPU）；
3. **独立进程 + 30 秒切片**：本地听写不跑在 AstrBot 进程里，而是由 `core/asr_worker.py` 子进程分片处理，每片 30 秒、0.75 秒重叠。即使 CTranslate2/ONNX 或损坏的音轨把子进程弄崩，bot 本体也不会跟着退出，只会拿到一条可读的失败原因；120 秒视频按 4 片处理，不会再一次性塞进一个大张量；
4. 转写结果缓存 90 天，同一 BV 号不会重复识别；默认最多处理 300 秒声音，超过部分不下载/不转写；
5. 字幕文本会进入视频理解提示词、自动评论提示词和后台活动记录；在聊天里问“这个视频说了什么”时，bot 能直接读到。

聊天里可以直接用 `/life transcript <B站链接>`，或由 bot 调用 `cyber_life_transcript`。本地听写第一次会下载模型，之后启动不再下载；如果只想要速度，可以把模型换成 `base`，只想要准确度可以换 `medium`。

B站字幕需要有效登录态；如果提示“这个视频没有可用的B站字幕”，说明该视频没有字幕轨，插件会自动尝试本地听写。

> 现成的 AstrBot 视频插件（如 BiliRead）主要读取 B 站已有字幕，视频解析类插件只负责下载/发送，不会替没有字幕的视频做长音频听写。因此这里没有硬塞一个会重复抢链接的插件，而是保留成熟的 faster-whisper 识别引擎，把运行方式改成独立进程分片，避免它把 AstrBot 本体拖崩。

## ComfyUI

默认使用内置的 SD1.5 txt2img API 工作流，只需要：

```json
{
  "comfyui_url": "http://127.0.0.1:8188",
  "comfyui_checkpoint": "v1-5-pruned-emaonly.safetensors"
}
```

如果要接自己的工作流，在设置里填写 ComfyUI **API 格式**的工作流 JSON 路径。支持占位符：

`{{prompt}}`、`{{negative}}`、`{{seed}}`、`{{width}}`、`{{height}}`、`{{steps}}`、`{{cfg}}`、`{{sampler}}`、`{{scheduler}}`、`{{checkpoint}}`、`{{filename_prefix}}`
（也兼容 `__PROMPT__` 这种大写形式）。

## 心情模型

四个维度都在 `[-5, 5]`，设置页显示为 0–100：

- 高兴：聊天里的正向/负向词、视频情绪
- 精力：感叹号、深夜活动会消耗
- 好奇：问句、视频主题、画画
- 压力：负面互动、画画失败

综合分 = `50 + 高兴*7 + 精力*3 + 好奇*2 - 压力*4`，并随时间向中性衰减。
高兴值 ≥ 2 时，评论和画画提示词会明显更轻快。

## 数据与安全

数据目录：`AstrBot/data/plugin_data/astrbot_plugin_cyber_life/`

```
accounts.json          账号元数据（不含密码）
sessions/              各平台 Cookie
browser_profiles/      Edge/Chrome 持久化用户目录（登录态）
mood.json              心情状态和历史
activity.json          今日配额、评论线索、动态
settings.json          设置页保存的覆盖项
media/                 二维码、抽帧、合成图、画作
```

- **不保存账号密码**，扫码得到的 Cookie / 浏览器 profile 只在本机。
- 评论是公开行为：默认每天最多 8 条、间隔 35–90 分钟、峰时再放慢；建议保持保守频率。
- 评论前会过滤明显不适合评论的视频（擦边/福利/低俗等关键词），并避免评价外貌、身体和穿着。
- 请只登录自己的账号，并遵守各平台社区规范。
- 插件不包含任何平台私有密钥；B站使用公开 Web 接口，小黑盒/贴吧使用浏览器页面操作。
- DeepSeek 余额查询只读取 AstrBot 当前提供商的 Key，在服务端请求余额接口；Key 不写入插件数据，也不会出现在接口响应或页面里。
